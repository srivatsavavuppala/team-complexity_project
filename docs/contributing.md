## Contributing

1. Fork the repo and create a feature branch
2. Run locally with `npm run dev`
3. Write tests where appropriate
4. Follow existing code style and structure
5. Commit with conventional messages where possible
6. Open a Pull Request with a clear description

### Project Standards
- Descriptive variable names; avoid abbreviations
- Validate inputs with Joi on server
- Handle errors with consistent JSON responses
- Keep components small and focused on the client

### Code of Conduct
Be respectful. See `LICENSE` for licensing terms.
